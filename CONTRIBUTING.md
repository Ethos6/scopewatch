# Contributing

Thanks for helping improve ScopeWatch.

- Keep checks passive, bounded, and easy to explain.
- Do not add exploit payloads, credential guessing, hidden network fan-out, or state-changing requests.
- Preserve the one-origin scope and private-address guard.
- Document new network behavior and its request limits in `README.md`.
- Keep runtime dependencies at zero unless a clear need is documented.
- Use focused pull requests and include a concise description of how the change was reviewed.
